## 3. iOS MAC 与设备标识

iOS CoreBluetooth 对多数 BLE 设备只公开 UUID，不公开硬件 MAC。该 UUID 只用于当前 iOS 设备上的连接路由，不能标成 MAC。

当前实现遵循以下规则：

- Yucheng SDK 返回 `macAddress` 时，列表显示真实 `MAC · XX:XX:XX:XX:XX:XX`。
- Veepoo 返回值符合标准 MAC 格式时，显示为 MAC。
- 只有 CoreBluetooth UUID 时，列表显示缩短后的 `iOS 标识`；设备详情保留完整 UUID。

不要根据设备名称、UUID 或日志字段推算、伪造 MAC。

- 本轮最后一次 Android W9/W9S 复测未完成：Mac 没有通过 ADB 识别用户的安卓手机。
- Android 复测前必须先断开 iPhone 上的 W9S，并关闭 iPhone 蓝牙，避免手表被占用后停止可连接广播。
- Android 11 及以下需开启系统定位并授予精确位置；Android 12 及以上需授予附近设备权限。
- 在线更新生产清单 URL、App Store App ID 和 Android 正式下载地址尚未提供。
- 服务端批量健康上传接口未配置时，本机同步正常，但云端状态会明确提示不可用。
- iOS 厂商 SDK 仍有 CoreBluetooth restoration identifier 警告；当前扫描、连接和重连实测正常。

## 8. 首次运行

```bash
flutter pub get
cd ios && pod install && cd ..
flutter analyze --no-pub
flutter test --no-pub
flutter run --dart-define-from-file=config/dev.json
```

iOS 本机签名请新建不入库的 `ios/Flutter/Local.xcconfig`：

```text
SAIDIAN_DEVELOPMENT_TEAM = 你的 Team ID
SAIDIAN_BUNDLE_IDENTIFIER = 你的唯一 Bundle ID
```

不要把 Apple ID、证书、描述文件、天气 Key 或其他密钥提交到 Git。

## 9. 在线更新

生产构建通过以下参数注入清单地址：

```bash
flutter build ipa \
  --dart-define-from-file=config/dev.json \
  --dart-define=SAYDIAN_UPDATE_MANIFEST_URL=https://正式域名/app-update.json
```

iOS 更新地址应指向 App Store，Android 更新地址应指向 HTTPS APK 下载页。具体清单格式见 `docs/app-online-update.md`。
