## 3. 最近设备扫描修复

当前设备流程为：

```text
设备页 → 开始查找 → 实时手表列表 → 点击手表 → 停止扫描
      → 连接/认证/同步 → 返回已连接手表功能页
```

最近已处理：

1. Release 混淆导致 `$Proxy4 cannot be cast to b5.d`：已增加 Veepoo/Inuker 回调保留规则。
2. 扫描结果不实时显示：已使用 EventChannel 逐台推送、按 MAC 去重、按 RSSI 排序。
3. App 扫描不到手表：发现宿主 Manifest 遗漏
   `com.inuker.bluetooth.library.BluetoothService`，已按 HBandSDK 文档补充，并确认进入 APK。

最新 APK：`03-最新Android测试包/Saydian-0.1.0+1-qa-release.apk`

## 5. 新电脑首次运行

建议把 `01-项目源码` 复制到短英文路径，例如 `D:\work\saidian-app`。安装 Git、
Flutter Stable、Android Studio/Android SDK 和 JDK 17。最近验证环境为 Flutter `3.44.9`、
Dart `3.12.2`、JDK `17.0.20`、Android minSdk 26、targetSdk 36。

Windows：

```powershell
Set-Location 'D:\work\saidian-app'
Copy-Item config\dev.json.example config\dev.json
flutter pub get
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --no-pub
```

如果中文目录导致 Flutter/Dart 路径问题，可将工程复制到英文路径，不需要携带本机
`.toolchains` 或构建缓存。

## 6. iOS 构建

iOS 必须在 macOS/Xcode 上执行：

```bash
flutter pub get
cd ios
pod install
open Runner.xcworkspace
```

Windows 开发者可使用 `.github/workflows/ios-test-ipa.yml`。签名构建仍需在私有 GitHub
仓库配置 `IOS_P12_BASE64`、`IOS_P12_PASSWORD`、
`IOS_PROVISIONING_PROFILE_BASE64`；Ad Hoc Profile 必须包含测试 iPhone UDID。
