# 设备功能实施与验证记录（2026-08-12）

## 依据

- 功能和数据结构：交付的 H5/小程序源码，重点参考 `pages/app/device.ts`、`pages/dial/index.ts`和 `pages/weatherForecast/index.ts`。

## 已接通的 Android 功能

| 功能 | 实际操作 | 用户保护 |
|---|---|---|
| 表盘 | 读取已安装表盘、切换系统/已安装/照片表盘 | 传输期显示进度，低电量给出明确提示 |
| 照片表盘 | 从手机相册选图并传送到手表 | 需用户主动选图，不自动读取相册 |
| 查找手表 | 开始/停止手表响铃或振动 | 只在手表报告支持时开放 |
| 相机遥控 | 打开手机相机，接收手表拍照事件 | 需相机权限，关闭页面后停止遥控 |
| 通话 | 读取通话连接/配对状态，设置自动连接和音频开关 | 仅对支持通话的手表开放 |
| 联系人 | 读取、新增、编辑、删除联系人及紧急联系人 | 姓名和号码本地校验，不伪造写入成功 |
| 消息通知 | 读写消息类型开关，在系统授权后仅转发用户开启的类型 | 提供“去设置”，队列有上限和超时 |
| 闹钟 | 读取、新增、编辑和删除手表闹钟 | 不超过手表返回的容量 |
| 天气 | 读写天气开关和温度单位，读取当前位置的 24 小时/7 日数据后下发 | 位置权限按需申请，天气密钥不写入源码 |
| 世界时钟 | 读取、新增和删除城市 | 上限 10 个，时区按 15 分钟精度下发 |
| 健康提醒 | 读写手表支持的久坐、饮水等提醒，兼容只支持旧版久坐提醒的手表 | 页面只显示手表返回的项目 |
| 辅助评估 | 读写手表支持的评估开关 | 明确标注仅供日常健康管理参考 |
| 屏幕显示 | 读写亮度、亮屏时长、抬腕亮屏时段和灵敏度 | 只显示当前手表支持的控件 |

## 实现边界

- 在线表盘商店没有从交付源码中找到可靠的公开资源列表；当前只管理手表中已安装的表盘和照片表盘。
- iOS 已保持与 Flutter 相同的方法契约，但上述新增设备设置没有在 iPhone + 目标手表上完成验证，因此 iOS 不宣称已接通。
- 天气接口、构建时密钥注入和“选择城市 → 获取预报 → 下发手表”已真机验证；本轮室内真机始终没有获得新的 GPS/网络定位结果，因此自动定位仍待室外复测。密钥只在构建时注入，没有写入 App 源码。
- 消息通知转发已在用户授权后完成一次真机闭环；验证结束后已关闭临时开启的“其他应用”开关，并将系统通知读取权限恢复为测试前的关闭状态。日常使用时仍需用户主动授权。
- 表盘实际切换和恢复已经验证；照片表盘未覆盖，因为没有用户原照片可用于无损恢复。
- 当前内部 QA 包使用 Android Debug 证书，不是应用商店正式签名包。

## 验收项

- 自动检查：`flutter analyze --no-pub`、`flutter test --no-pub`、Android Kotlin 编译、Android release 构建。
- 本轮真机检查：扫描、连接、身份确认、固件读取、健康数据同步、完整表盘列表、表盘切换与恢复、闹钟增删改查、查找手表、通知转发，以及城市天气下发。
- 后续真机检查：自动定位天气、照片表盘传输，以及 iPhone + 目标手表。
- 每个不支持项必须显示“当前手表不支持此功能”，不允许点击后伪造成功。
